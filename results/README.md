# Result files

All values are percentages. `ACC` corresponds to weighted accuracy (WA), and
`BACC` corresponds to unweighted accuracy (UA). The CSV files record the values
used in the manuscript; no values are inferred from figures.

- `iemocap_5fold.csv`: reproduced MemoCMT and Cross-MILA on five held-out sessions.
- `esd_5fold.csv`: reproduced MemoCMT and Cross-MILA on five held-out speaker pairs.
- `meld_official.csv`: official MELD test split.
- `controlled_ablation.csv`: fusion/objective two-factor study.
- `structural_ablation.csv`: Cross-MILA component study under CE.
- `unimodal_baselines.csv`: HuBERT-only and BERT-only fold results.
- `efficiency/`: raw benchmark exports retained from the reported hardware run.
